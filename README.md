# Mini project
#### Комплексный анализ клиентской активности и сегментация базы
#### Описание:В рамках данного проекта реализован SQL-скрипт для глубокой аналитики транзакционной активности клиентов за годовой период (2015-2016 гг.). Запрос решает задачу мониторинга ключевых бизнес-метрик (KPI) и сегментации аудитории.
#### Основные блоки анализа:
#### 1)Динамика по месяцам: Расчет среднего чека, количества операций и уникальных клиентов в каждом месяце.
#### 2)Долевой анализ: Определение доли выручки и количества операций каждого месяца в общем годовом объеме (Market Share внутри года).
#### 3)Демографический профиль: Анализ гендерной структуры (M/F/NA) — расчет % соотношения затрат и количества клиентов в разрезе пола для каждого месяца.
#### 4)Возрастная сегментация: Группировка клиентов по возрасту (шаг 10 лет) с расчетом совокупных продаж и количества транзакций для каждой группы.
 ### Этот анализ является этапом подготовки данных перед постороением прогнозных моделей или расчетом LTV
